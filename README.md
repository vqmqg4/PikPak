The multi-platform support gets thumbs up. Being able to access your files from any device without hassle is exactly what cloud storage should do. The Telegram bot integration is particularly popular with users who share a lot of content through that platform.

### The Not-So-Good Stuff

Stability issues come up frequently in reviews. Some users report that downloads can suddenly slow down to a crawl (around 280 kbps) or fail entirely, claiming files are offline even when they're not. Connection problems make it difficult to access files, with login issues lasting for hours at a time.

The data center fire incident in September 2024 shook user confidence. The service was down for over 9 days, and while PikPak compensated users (9 days premium for free users, 18 days for premium users), it highlighted concerns about the stability of the infrastructure.

Bulk downloading on iOS is a pain point. The app doesn't support downloading multiple files at once, so you're stuck downloading one file at a time. The Windows app does have this feature, but it's an inconvenience if you primarily use your phone.

Upload quotas can be limiting. There are daily limits on how many files you can upload (up to 1,000 per day) and size restrictions (4GB per file on web, 20GB on desktop). For users dealing with large amounts of data, these restrictions feel arbitrary.
